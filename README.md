## 阅读顺序

1. 先读 [`项目档案/当前进度.md`](项目档案/当前进度.md)，了解当前阶段和正在讨论的问题。
2. 再按任务读取相关专题：
   - [`创作基线.md`](项目档案/创作基线.md)：长期稳定的审美与创作原则。
   - [`超凡底层探索.md`](项目档案/超凡底层探索.md)：世界与力量候选、明确排除方向。
   - [`大纲.md`](项目档案/大纲.md)：当前大纲状态与已获认可的局部推进。
   - [`终局工作模型.md`](项目档案/终局工作模型.md)：后期候选框架，只在相关讨论中读取。
   - [`开放问题.md`](项目档案/开放问题.md)：尚需作者决定的问题。
3. Codex 还应遵守 [`AGENTS.md`](AGENTS.md) 和项目内 `novel-*` 技能。

## 状态规则

- **已确认**：作者明确采纳，可以作为后续依据。
- **当前方向／暂定**：用于继续工作的方案，仍可修改。
- **候选**：可以比较和推演，尚未采纳。
- **举例／试写**：只用于说明或测试，不构成设定。
- **否决／停止推进**：保留最小理由，避免无新依据时反复提出。
- **开放问题**：尚无答案，不得由 AI 自行补成事实。

`资料/` 只保存确有长期溯源价值的作者原始交接，`研究/` 保存仍可能复用的专题研究。两者只供本地按需查阅，默认不上传 GitHub，也不作为每轮必读内容。普通对话、临时备份、未采纳提案和可重新取得的工具源码不长期保存。共享档案应尽量自包含；找不到依据时应说明，不用猜测补齐。
