# 世界与修炼适配模块

先读 [项目协议](../novel-project/references/project-protocol.md) 和相关已确认/暂定规则。

从当前问题出发，区分底层规律、文明理论、文化名称和实际技术。说明能力条件、边界、代价与可观察后果，追问它对资源、寿命、制度、职业、家庭和普通生活的影响。需要时提出竞争解释，保留未决处。

规则无需等同现实物理，也不把修炼强行改造成工程论文。神魂不是意识的同义词；修炼细节暂停的部分不主动扩填。世界发展数千年，既有研究和制衡需可信，但具体政治制度仍由作者选择。

按剧情维护地点、交通、势力、公共设施及资源状态；只记录已有变化。新规则检查与过去事件兼容性，不靠新增例外救场。

输出与问题相称的分析、方案与影响；候选获采纳后交由 `novel-memory` 维护。参考来源为 chinese-webnovel-skills 的 world 与 worldbuilding，已去掉全面填表、固定文件名和强制爽点要求；版本见根目录 `配置说明.md`。
