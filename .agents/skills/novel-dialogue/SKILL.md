# 对话适配模块

先读 [项目协议](../novel-project/references/project-protocol.md)、人物档案及场景前后文。

明确说话者想获得或保护什么、对谁说、知道和误解什么、关系与身份如何影响表达。人物能直接诚实表达，也可试探回避，不强行每句潜台词。

依据生活经验、职业、情绪和关系区分声音；不要仅换口头禅。东方幻想社会中的用语须合语境，不自动引入现代网络梗，也不把整章改成文言。

保留自然句长和必要口语，允许日常对话建立亲疏与生活。避免说明书对白，但不机械删除解释、语气词、副词或全部完整句。动作与停顿按场景需要使用，不为去AI味切碎语言。

按用户要求输出改写片段或对照，并说明关键变化；不为了造金句改变人物立场、事实和剧情。新创作台词尚未被接受时保持草稿。

改编自 chinese-webnovel-skills 的 dialogue / dialogue-library，保留场景目的与声音一致性，移除短狠台词、围观反应和传播金句要求。
