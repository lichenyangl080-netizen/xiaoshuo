# 文本研究

先明确当前问题，例如歌谣线索的公平性、第一卷目标如何变化、日常如何承载世界。优先研究能回答问题的章节与场景，而不是先铺一套百科资料。

每份研究写明作品、版本/来源、实际阅读范围、文本定位、观察、推断与适用边界。只读摘要时标为摘要研究；不能宣称读过正文。无法访问原文就说明证据缺口，不编造引文或章节。

分析层次按问题选择：全书动力、卷级因果、篇章节奏、场景选择、信息顺序和语言。每项技法连接具体文本证据，并解释对本书的帮助及不适用处。必要引用应简短，不保存或输出大段替代原作的内容。

《诡秘之主》优先研究世界规则与生活、人物独立行动、线索首次出现的自然性、揭晓后旧事实仍成立、阶段目标接续；不照搬途径、组织、人物、桥段或特定句法。

研究方法迁移到本书时标为建议或试验，不自动转成设定。不以“名作这样写”代替对本书的因果论证。不预设哲学暗线需要演讲表达，也不把一切日常细节都改成谜题。
