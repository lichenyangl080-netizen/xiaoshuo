# 人物适配模块

先读 [项目协议](../novel-project/references/project-protocol.md) 和涉及人物的前文。

从人物要什么、为何在此时行动、知道/误解什么、愿付何种代价、底线和自我矛盾出发。用关键选择验证人物，区分稳定价值与可能变化的判断。不要强行分配偏执、自毁、反差或三词性格。

配角有自己的事务、能力、亲疏关系与未来。若主角不出现，他会如何行动？反对者可以有合理利益，不必都承担被打脸功能。保持成熟文明中的聪明人真的聪明。

主角的信息位置必须有经历依据；结合其主动选择与实际后果理解成长，有成本时核对其依据，不为塑造人物额外强加损失。不能拿天赋或地球知识自动解释优越性。

人物声音来自教育、身份、关系、当下目的与习惯，随场合变化；不必人人有口头禅。输出人物方案、选择例证与开放问题，获采纳后入人物档案。

改编自 chinese-webnovel-skills 的 character；上游的标签、强制非理性点、反派打脸层级与固定CP套路不适用本项目。
