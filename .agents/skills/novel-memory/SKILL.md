# 档案适配模块

读 [项目协议](../novel-project/references/project-protocol.md) 的状态规则和档案路径，先检查现有文件；不存在则按已有内容最小建档，不创建空白百科。

接续：读当前进度、相关决定和必要原文，说明阶段、已知内容及当前问题。不把“继续项目”自动理解成“写下一章”。

更新：记录源自作者的决定与理由、人物变化、时间、资源、知情状态和伏笔。AI草稿新增内容属于草稿；候选与举例不成为正式世界事实。保存决策变化，旧结论标为被替代。重要事实保留章节或原文定位及适用时间；区分作者改设定与人物在故事中发生变化，后者不能覆盖其早期状态。只维护本次相关增量，不反复生成全量交接。

已确认正文或作者修改优先核对；档案摘要不能抹掉原文细节。真相与角色信念分层保存，人物知道信息要有渠道和时机。保留开放问题及研究证据缺口。

只对相关任务授权的内容执行写入。报告实际更新文件和未决冲突，不承诺永久记忆或自动后台同步。版本操作不默认提交、推送、覆盖确认稿或回滚用户文件。
