# 大纲适配模块

先读 [项目协议](../novel-project/references/project-protocol.md)，识别作者要求的层级和当前确定程度。

远期：终点方向、长期欲望、核心矛盾和真相候选；中期：阶段目标、转折条件和人物选择；近期：具体行动、阻碍、结果和后果。不能把当前没有答案的问题随手填成终局。

卷级按实际情节组织目标、压力、信息变化、高潮、收束及后续动力，核对已有代价与持续后果，不强加固定要素。采用多人共同破局时，检查分工的因果依据；参与者及其贡献由当前选定情节决定，不固定主角与强者的角色。

信息布置记录事实何时出现、当时合理解释、谁能接触、何种证据促成重解。揭示不能追溯改写已经展示的事实；隐瞒靠视角与处境，不靠旁白说谎。

章纲粒度按任务决定，写清场景人物目的与变化；日常也可建立关系、欲望、生活和期待，不强迫每章冲突爆发。没有固定三章爽点、六章推进、卷字数或付费节点要求。

输出必要结构与待选分歧；没有写作请求时不自动扩正文。改编自 chinese-webnovel-skills 的 outline，保留分层大纲与伏笔管理，移除固定商业节奏和金手指成长配额。
